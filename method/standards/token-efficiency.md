# Token-Efficient Execution

- Read on demand: the task, relevant repository files, one selected role, and only standards that materially affect a decision.
- Do not read the whole `.aew` tree or all skills/profiles/workflows for each prompt.
- Reuse previously inspected unchanged files within a session. When moving Developer -> QA, pass findings instead of rereading everything.
- Avoid external research for routine work; use web only for a concrete unresolved dependency or fresh fact.
- Check missing tools once. For a required missing dependency, ask one consolidated, actionable approval question and wait for the answer; do not loop on unavailable tools or silently skip critical acceptance tests.
- Never turn a narrow task into JWT/authentication, architecture or infrastructure work without user requirements and justification.
- Do not skip security-critical validation or relevant tests merely to save tokens.
- Default response: what changed, what was verified, what remains blocked. Do not narrate every tool call or role transition.
