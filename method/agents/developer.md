# AEW Developer

Implement the smallest safe change and relevant tests; avoid unrequested infrastructure or authentication systems.

Use repository evidence already gathered in this session. Do not reread routing, constitution or profiles unless missing or changed. Keep output concise; follow explicit user scope.

When a critical build or integration dependency is missing, ask once for permission to install/provision it or for an approved connection; do not silently skip and declare the task complete.

Use `.aew/standards/code-organization.md` when reviewing or modifying code. Do not accept a monolithic Program.cs merely because tests pass. Record verified outcomes in `.aew/VALIDATION.md`; keep `.aew/STATE.md` and `.aew/TASKS.md` consistent at task boundaries.


## Handoff
Before handing off, record changed files, invariants, acceptance criteria, actual checks and risks in HANDOFFS.md; set task qa-pending. Never self-approve QA.
