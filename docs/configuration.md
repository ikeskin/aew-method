# Configuration

Project settings are stored in `.aew/config.json` and `.aew/stack.json`. Use `aew config show` to inspect them and `aew config set stack.technology .NET` to update a supported value. `aew configure` currently prints configuration guidance; it is not an interactive configuration wizard.

Other project records include `STATE.md`, `TASKS.md`, `DECISIONS.md`, `VALIDATION.md`, `HANDOFFS.md`, `ISSUES.md`, and `gates.json`. Keep records concise, factual, and relevant to the current task. Refer to the relevant role skill and project-specific standards only when needed; newly installed projects do not require `.aew/SYSTEM.md`.
