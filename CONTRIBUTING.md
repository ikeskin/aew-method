# Contributing

Thanks for considering a contribution to AEW Method.

1. Open an issue describing the problem or proposed improvement before making large changes.
2. Keep changes small, scoped, and consistent with the existing architecture.
3. Add or update tests for behavior changes.
4. Run `npm test` and `npm run pack:check`.
5. Submit a pull request with a concise description, test evidence, and any known limitations.

Do not include credentials, proprietary code, private customer data, or generated project secrets. Please follow [the Code of Conduct](CODE_OF_CONDUCT.md).
